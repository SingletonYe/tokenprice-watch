What the winner costs

Extract currently leads this list. At $0.040 per 1M input tokens and Free per 1M output tokens, a workload that processes 100M input and 25M output tokens per month bills about $4.00 per month. The most expensive paid model in the catalogue is $262 per 1M blended — 8750× more.

How to read this ranking

  1. Blended price assumes three input tokens for every output token. If your mix is different, use the calculator and your own numbers.
  2. Context window caps how much you can send per call, but long context usually costs a premium above roughly 128K tokens.
  3. Benchmark indices come from the provider's published model metadata and are absolute published scores, not an endorsement.
  4. Caching can cut repeat-context costs by 60–90% — see cache pricing.
