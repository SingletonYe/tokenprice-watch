$1.10 per 1M input tokens and $4.40 per 1M output tokens, which is $1.93 per 1M tokens at a 3:1 input-to-output mix. Cached input reads cost $0.550 per 1M with this provider's cache tier.
What is o3 Mini High's context window?
200,000 tokens, with up to 100,000 output tokens per request.
Is there a cheaper alternative to o3 Mini High?
Yes — OpenAI: gpt-oss-20b at $0.036 per 1M blended, Inception: Mercury 2.5 at $0.068 per 1M blended, NVIDIA: Nemotron 3.5 Lightning at $0.103 per 1M blended. The full ranking is on the cheapest API pages.
Is o3 Mini High expensive?

What inputs does it accept?
Accepted input: text, file. Output: text.
