Frequently asked

How much does Glimpse cost per 1M tokens?
$0.600 per 1M input tokens and $3.00 per 1M output tokens, which is $1.20 per 1M tokens at a 3:1 input-to-output mix. Cached input reads cost $0.060 per 1M with this provider's cache tier.
What is Glimpse's context window?
262,144 tokens, with up to 256,000 output tokens per request.
Is there a cheaper alternative to Glimpse?
Yes — Mistral: Mistral Nemo at $0.029 per 1M blended, ScaleDown: Extract at $0.030 per 1M blended, ScaleDown: Summarize at $0.030 per 1M blended. The full ranking is on the cheapest API pages.
Is Glimpse expensive?
It is the 224th cheapest of 366 paid models, so 61% of the catalogue is more expensive per token.
What inputs does it accept?
Accepted input: text, image, video. Output: text.
