Frequently asked

How much does MiniMax M3 cost per 1M tokens?
$0.300 per 1M input tokens and $1.20 per 1M output tokens, which is $0.525 per 1M tokens at a 3:1 input-to-output mix. Cached input reads cost $0.060 per 1M with this provider's cache tier.
What is MiniMax M3's context window?
524,288 tokens, with up to 512,000 output tokens per request.
Is there a cheaper alternative to MiniMax M3?
Yes — Upstage: Solar Pro 4 at $0.158 per 1M blended, NVIDIA: Nemotron 3.5 Super VL at $0.237 per 1M blended, DeepSeek: DeepSeek V4 Pro 0423 at $0.261 per 1M blended. The full ranking is on the cheapest API pages.
Is MiniMax M3 expensive?
It is the 145th cheapest of 366 paid models, so 39% of the catalogue is more expensive per token.
What inputs does it accept?
Accepted input: text, image, video. Output: text.
