Methodology

Everything on this site is derived from one public data source, refreshed once a day, and committed to a public repository. Here is exactly how.

Source

Model metadata and prices are pulled from the public OpenRouter models catalogue (openrouter.ai/api/v1/models), a machine-readable list of endpoints, per-token prices, context windows, cache rates, modalities and published benchmark indices. No private API key is used and no scraping of HTML price pages happens.

Refresh schedule

Once per day, shortly after 06:17 UTC. Each run writes a dated snapshot to data/snapshots/, computes the diff against the previous snapshot into data/changes/, and rebuilds every page. If the collector receives fewer than 50 models it aborts without overwriting data, so a bad upstream response cannot wipe the site.

Units

All prices are USD per 1,000,000 tokens. The upstream source publishes per-token prices; multiply by 1,000,000 and round for display. Blended price = 0.75 × input + 0.25 × output, a 3:1 input:output ratio that matches typical chat and RAG traffic. Ranked tables always state which column they are ordered by.

Benchmark indices

Intelligence, coding and agentic indices are quoted from the catalogue's published benchmark field. They are third-party absolute scores, not the site's own measurements, and they are only available for a subset of models — models without a published index are shown with a dash rather than an invented value.

Accuracy limits

  • List prices change intraday; this site guarantees at most a 24-hour lag.
  • Long-context tiers, batch discounts and minimum commitments are not always representable per token — verify before signing anything.
  • Free endpoints carry undocumented rate limits and licence terms.
  • Variants (:batch, :free) are shown on the model page rather than as separate models, to avoid duplicate pages.

Reproducibility

The generator is a small Python program with no third-party dependencies. Anyone can clone the repository, run two commands, and rebuild this site from the committed snapshots.
