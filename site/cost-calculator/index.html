Estimates use published list prices and ignore free tiers, minimums, volume discounts and failed-request retries. Cache percentage applies to input tokens only and uses the cached-input rate where a provider publishes one; models without a cache tier are billed at full input price.

How to cut the bill

  1. Cache the system prompt. A 2,000-token instruction block sent on every request is the single largest avoidable cost at scale; cache reads are typically 10–25% of the input rate.
  2. Route by task. Most production traffic does not need your most expensive model. Send classification and extraction to a small model and escalate only hard cases.
  3. Cap output tokens. Output is usually 3–5× the input price per token, and verbose answers are pure cost.
  4. Use batch endpoints for anything that is not interactive — see batch pricing.
  5. Re-check the table monthly. Prices fall; a model that was wrong for your budget last quarter is often the right answer now — that is why this tracker updates daily.
